# Phantom Blade Zero

A dark ink-black Omarchy theme with lacquer-red and brass accents, inspired by
the wuxia and steampunk look of Phantom Blade Zero. This is a mood piece, not
an extraction of the game's official palette.

## Install

```sh
omarchy theme install https://github.com/gosumarchy/omarchy-phantom-blade-zero-theme
```

## Window look

The theme sets the palette, the window border colors, the translucent bar,
menus, popups and notifications, and the icon theme. Transparency values match
the Rainy Harbor, Rainy Window and Rainy Storm themes.

Omarchy does not load Lua from installed themes, so window opacity, corners,
border width and blur have to go in your own `~/.config/hypr/looknfeel.lua`.
Use the same block as the Rainy themes README.

## Wallpapers

Generated procedurally, not photographed or taken from the game. Three variants:

- `backgrounds/0-phantom-haze.jpg`: full colour, brass light shafts and lantern bokeh
- `backgrounds/1-phantom-haze-ash.jpg`: near-grayscale with a warm tint
- `backgrounds/2-phantom-haze-steel.jpg`: grayscale with a cool steel tint

Cycle them with `omarchy theme bg next`.
